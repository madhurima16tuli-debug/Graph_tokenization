# Graph Tokenization
This repository contains the codebase for molecular graph tokenization and self-supervised pre-training, building upon the **Mole-BERT** framework. The project implements a multi-tokenizer architecture using Hierarchical Vector Quantized Variational Autoencoders (HVQVAE) to map molecular structures into discrete token spaces for down-stream Graph-LLM alignment.

1. The link for the datasets used is within the README file inside Mole-BERT-main
2. hvqvae_gin.py is the script for GIN based tokenizer and hvqvae.py is the one for GPM based tokenizer.
